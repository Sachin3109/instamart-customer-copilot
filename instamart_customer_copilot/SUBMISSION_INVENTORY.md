# Submission inventory

This package includes the four required project parts and their generated artifacts.

| Requirement | Included location |
|---|---|
| Data generation and cleaning | `generate_data.py`, `part_a.py` |
| SQL analytics | `sql/queries.sql`, `data/instamart.db` |
| Clean datasets | `data/clean/` |
| Segmentation and lapse modelling | `part_b.py`, `outputs/customer_segments.csv`, `outputs/retention_list.csv`, `outputs/lapse_model.joblib` |
| Ticket triage | `part_c.py`, `outputs/triage_results.csv`, `outputs/triage_budget_demo.csv` |
| Policy RAG and refund agent | `part_d.py`, `data/policies/`, `outputs/agent_runs.jsonl`, `outputs/refund_ledger.jsonl` |
| Checkpoint / resume evidence | `state/` |
| Single-command pipeline | `run_all.py` |
| Project documentation | `README.md` |

**Important:** Generated artifacts are included for inspection. This is a project package, not a hosted GitHub repository. The repository owner must create or select a public GitHub repository and upload the contents of this folder to its `main` branch.
